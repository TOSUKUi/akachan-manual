# 03. 外部リンクと開示（EC リンクのルール）

- **確認日**: 2026-09-01
- **方法**: 各 URL をブラウザ相当の User-Agent 付き curl で直接取得し、リダイレクト追跡後の最終 HTTP ステータスを実測しました。検索フォーマットは各サイトのトップページ HTML から検索フォームの `action` とパラメータ名を抽出して確定したもの（推測による URL は採用していません）。
- **前提**: このサイトは GitHub Pages 上の公開静的サイトで、アフィリエイト・広告収入は一切ありません。新しい「月齢別タイムライン」ページで、各月齢に必要になる育児用品の「探し先リンク」を読者に提供することを想定しています。

## 2. EC リンクを貼る際のルール（アフィリエイトなしの場合）

### 2.1 基本方針

- このサイトはアフィリエイト・広告収入がありません。そのため「PR」表記や「アフィリエイトリンク」の開示義務は発生しませんが、**読者に紛らわしさを与えないため、リンクの性質（EC サイトへの検索リンクであること）を明示します**。例: 「購入を検討するときはこちらで探せます（Amazon の検索ページが開きます）」。
- 免責文（サイト全体のフッター）に「このサイトはアフィリエイト・広告収入を得ていません。リンクは情報提供のためのものであり、売上の一部が当サイトに入ることはありません」と 1 行明記することを推奨します。これが最も確実な開示です。
- リンクは `rel="noopener noreferrer"` を付けて新しいタブで開きます（`target="_blank"` を使う場合）。

### 2.2 やってはいけないこと

1. **価格を書かない**。EC の価格はセール・在庫・出品者により常に変動します。サイト側が価格を記載すると、すぐに古くなり、読者に誤った情報（実際より安い・高い）を与えます。さらに、価格が実際より安く見える表示は景品表示法上の「有利誤認」にあたる可能性があるため、第三者が価格を掲載するのは避けるのが安全です。タイムラインのページでは「金額の目安」も書かない方針にします（タスク 1 の指示と同じく、価格は一切扱わない）。
2. **商品直リンクを貼らない**。理由は第 3 節で詳しく述べます。
3. **公式サイト・パートナーと誤認させる表示をしない**。Amazon 等のロゴを無断で大きく使ったり、「Amazon 公式」「西松屋公式」と誤解させる表現は避けます。テキストリンクで「Amazon.co.jp で検索」のように書くのが安全です。
4. **広告表示を隠さない**。将来アフィリエイトを導入する場合は、景品表示法（令和 5 年改正、2023 年施行）の「一般消費者が事業者の表示であることを判別することが困難である表示」の禁止（いわゆるステルスマーケティング規制）に留意し、「PR」「広告」と明示します。現状はアフィリエイトなしなので該当しませんが、将来の変更に備えて方針として記録しておきます。
5. **比較・評価の体裁で誘導しない**。「この商品がベスト」のような特定商品の推奨・比較を EC リンクと組み合わせて書くと、広告との誤認や根拠のない優良誤認表示に近づきます。タイムラインは「いつ、何が要るか」の情報提供にとどめ、商品の優劣の断定はしません。

### 2.3 Amazon の商標・規約について

- アソシエイト（アフィリエイト）プログラムに参加していない場合、Amazon.co.jp へのテキストリンクを貼ること自体は問題ありません。ただし「Amazon」「Amazon.co.jp」のロゴは商標であり、公式のパートナーでないのにロゴを使う表示は避けます（誤認防止のため）。
- アフィリエイトを導入する場合は Amazon アソシエイトの運営規約（リンクの形式、商品リンクの使い方、禁止事項）に従う必要があります。現状は導入していないため、プレーンテキストの URL リンクのみを使用します。
- Rakuten などの他モールも同様で、ロゴ・画像の無断使用は避け、テキストリンクにします。

## 3. リンク切れ問題と検証日の記録

### 3.1 商品直リンク vs 検索リンク

| 観点 | 商品直リンク（ASIN・商品 ID） | 検索リンク（`s?k=` 等） |
|---|---|---|
| リンク切れ | **在庫切れ・リニューアル・出品者の出品停止で頻繁に切れる**。実測でも存在しない ASIN は 404（#12） | キーワード検索は常に有効。モール側の検索 UI が変わらない限り切れない |
| メンテナンス | 商品ごとに検証が必要で、数が増えると破綻 | フォーマットが固定されていれば、全リンクを 1 つのルールで検証できる |
| 読者にとって | クリックして在庫切れだと「使えないリンク」 | 検索結果に現在買える商品が並ぶ。目的の商品が別メーカーにあっても代替が見つかる |
| 更新頻度の影響 | 価格・在庫・評価の変動をサイトが追えない | 価格や在庫をサイト側で書かないので、陳腐化しない |

**結論: 検索リンクを採用します。** 商品直リンクは「読者が今すぐ買える」利点はありますが、リンク切れのメンテナンスコストと、価格・在庫情報をサイト側で持てない問題があり、静的サイトの運用に合いません。

### 3.2 検証日の記録方法

既存の fact と同じ鮮度管理の考え方を適用します。

- 各 EC リンクに「最終確認日（verified）」をデータとして持たせます。既存の frontmatter の `sources[].checked` と同じ形式（`checked: 2026-09-01`）を使います。
- 検証ルール: リンクの検証は「HTTP ステータスが 200（または恒久的リダイレクト 301 の追跡後 200）」であることを確認します。404・500・DNS 解決不能は不合格とします。
- 180 日ルール: 既存の `last_verified` の 180 日鮮度警告（AC-11）と同様に、EC リンクの検証日が 180 日を超えたらビルド時に警告を出す仕組みに含めます。検索フォーマットは固定なので、実際のチェックは「フォーマットが壊れていないか」の再確認（年に 2 回程度のスポットチェックで十分）です。
- 検証の自動化: 検索 URL はフォーマットが決まっているため、ビルド時のリンクチェッカー（curl で 200 を確認するスクリプト）に載せやすいのが利点です。商品直リンクだと、この自動検証が成り立たない点も直リンク不採用の理由です。

## 4. 姉妹サイト（shinagawa-hojokin）の前例の適用

hojokin の FACTS.md と本プロジェクトの `docs/specs/0001-baby-guide-static-site.md` から、リンクに関する前例は次のとおりです。

1. **sources[] は公式ソースのみ**。AC-4 で「根拠 URL は frontmatter の sources[] に含まれることが必須」と定義されています。hojokin も「検証済みファクトシート」として公式ページのみを根拠にしています。
2. **検証方法の明記**。hojokin は「本文・出典に載せた URL はすべて直接 HTTP リクエスト（curl）で到達性（HTTP 200 / 301）を確認済み」と明記しています。本調査も同じ方法を踏襲しました。
3. **ブログ・SEO サイトは根拠にしない**。医療・制度の事実の根拠には、個人ブログや SEO 目的のまとめサイトを使いません。

**EC リンクの扱いの結論**:

- EC の検索リンクは「根拠（エビデンス）」ではありません。**sources[] には入れません**。
- タイムラインのアイテムに「探し先リンク」として別カテゴリ（例: frontmatter の `shop_links` や本文中の専用行）で持ち、sources[] とは分離して管理します。これにより「根拠リンクの無い事実はビルド失敗」という AC-4 の検証に EC リンクが巻き込まれず、かつ公式ソースだけの根拠規律を崩しません。
- EC リンクにも検証日を持たせ、180 日警告の対象に含めます（3.2 節）。

## 5. 推奨（まとめ）

1. **検索リンクを採用する**（商品直リンクは不採用）。理由: リンク切れが少ない、自動検証できる、価格・在庫をサイト側で持たなくて済む。
2. **採用する検索フォーマット（7 件、2026-09-01 実測 200）**:
   - Amazon: `https://www.amazon.co.jp/s?k={キーワード}`
   - 楽天市場: `https://search.rakuten.co.jp/search/mall/{キーワード}/`
   - 西松屋: `https://www.24028-net.jp/item_list.html?q={キーワード}&searchbox=1`
   - アカチャンホンポ: `https://www.akachan.jp/products/?Search%5Bkeyword%5D={キーワード}`
   - アカチャンホンポ月齢絞り込み（任意）: `https://www.akachan.jp/products/?Search%5Bage%5D=0-3_months` 等
   - ユニクロ: `https://www.uniqlo.com/jp/ja/search?q={キーワード}`（URL エンコード必須）
   - サイボウは EC ではないため対象外
3. **表示はテキストリンクのみ**。ロゴ・画像は使わない。`rel="noopener noreferrer"` を付ける。リンクの性質（EC 検索ページが開くこと）をリンク文で明示する。
4. **価格・金額は一切記載しない**。商品の優劣の断定もしない。
5. **開示文をサイトの免責に追加する**: 「アフィリエイト・広告収入はありません。EC へのリンクは情報提供目的です」。
6. **EC リンクは sources[] に入れず、専用のフィールドで管理する**。検証日を持たせ、180 日鮮度警告の仕組みに載せる。
7. **将来アフィリエイトを導入する場合**は、景品表示法（2023 年改正のステマ規制含む）に従い「PR」明示と Amazon アソシエイト規約への準拠が必要になる点を、方針として記録しておく。

## 6. 残リスク・注意点

- 検索 URL のフォーマットはモール側のサイト改修で変わり得ます。年に 2 回程度のスポット再検証が必要です（180 日警告と連動）。
- アカチャンホンポの月齢フィルタの値（`0-3_months` 等）は、サイト側の改修で変わる可能性があります。フィルタ付きリンクは任意機能とし、壊れたらキーワード検索（#5）にフォールバックできる設計が安全です。
- 本調査は curl による HTTP ステータス確認が中心です。ブラウザで検索結果が正常に描画されることは、リリース前に各 1 件ずつ目視確認することを推奨します。
